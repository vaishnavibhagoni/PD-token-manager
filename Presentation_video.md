
## Project Presentation Video

This video provides an overview of the **Priority-Based Digital Token Management with Anti-Starvation Scheduling for VSDBabySoC** project.

In this presentation, I explain:

- **Project Overview:** The problem statement, objectives, and proposed solution.
- **RTL Design:** The Verilog HDL modules and overall system architecture.
- **Functional Simulation:** The testbench, simulation process, and waveform analysis.
- **Tools and Technologies Used:** Verilog HDL, OpenROAD-flow-scripts, and the SKY130HD standard-cell technology library.
- **Physical Design:** Synthesis, floorplanning, placement, clock-tree synthesis, routing, and final GDSII layout generation.
- **Project Summary:** Key design goals, implementation results, and verification status.

The main objective of this project is to prevent starvation of normal requests while maintaining priority-based scheduling. The scheduler allows a waiting normal request to be served after three consecutive priority services, provided both types of requests are waiting.
